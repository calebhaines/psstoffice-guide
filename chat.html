Your little signing stamp

An Ed25519 key gives your notes a recognizable signing identity. A valid signature proves control of that key, not a real-world identity. Your private key stays in page memory for this room and is cleared when you leave this room or close the page.

To reuse your identity, deliberately download the private key and keep that file secret. It is unencrypted; anyone with the file can sign as this key. Nothing is saved automatically.

The little filing cabinet

Any file type, up to the server’s current upload limit. Each room can receive one new file every 30 seconds. Each file disappears from the room after two hours. Downloaded copies stay on your device.

Files are untrusted. Download only from someone you trust; opening files can be unsafe. Files and their uploader names are unsigned. “Sign my notes” applies to chat notes only. Files are never previewed here.
